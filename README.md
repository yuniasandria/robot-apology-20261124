# The Robot Apology

A two-line robot confession for the [make.fun](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59) bounty "The Robot Apology".

Line one is a robot apologizing in a single sentence for one specific
mistake. Line two is one sentence saying what the robot learned and
what it will do differently — a lesson that follows from that exact
mistake.

## Run

```sh
python3 main.py
```

The program writes the two-line text to `/output/entry.txt`
(1–400 characters, UTF-8, pure Python standard library).
